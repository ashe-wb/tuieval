# tuieval brand files

The icon is the **Scorecard Mosaic**: a 3 × 3 grid of verdict cells (models × use cases, as on the TUI's Setup screen) whose last cell is the terminal cursor.

| File | Use |
|---|---|
| `tuieval-icon.svg` | master icon |
| `tuieval-icon-animated.svg` | the icon with a blinking cursor cell |
| `tuieval-icon-16.svg`, `tuieval-icon-16.png`, `tuieval-icon-32.png` | drawn on the 16 px pixel grid, for favicons and small sizes |
| `tuieval-icon-48.png` … `tuieval-icon-1024.png` | larger sizes (avatars, app icons) |
| `favicon.ico` | 16, 32 and 48 px |
| `social-preview.png` | 1280 × 640 card for links (GitHub: Settings → Social preview) |
| `readme-header.png` | 2400 × 600 README banner |

Colours: PASS `#5fd3a3`, INCONCLUSIVE `#f5b544`, FAIL `#ee6b6e`, cursor `#f4f1e8`, tile `#2a2f5c` → `#191c3a`. The name is set in JetBrains Mono Bold.
